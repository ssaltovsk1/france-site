# Роли 26 + 15

Это рабочая новая раздача загрузов для игры:

- 26 активных загрузов для игроков;
- 15 второстепенных загрузов для упоминаний, мастерских выходов и фона;
- основа взята из старых 60 полных загрузов в `kventas/`;
- городские роли сведены к нужным профессиям: 1 лавка, 2 хлебопекаря, 2 модистки, 2 театр/сцена, 1 кафе, 2 печать/типография;
- Шогенов Даниэль вынесен в тюремщика, Строганов Дима — в приходского священника.

## Правило сборки

Финальным артефактом считается загруз: текст для игрока в формате старых квест, с блоками "Кто ты и что ты пережил", "Связи", "Словарь" и мастерским блоком убеждений.

Прежние черновые файлы больше не используются для публикации.
