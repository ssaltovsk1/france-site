# Роли 26 + 14

Рабочая папка новой версии загрузов под состав из 26 активных игроков и 14 второстепенных ролей.

Основные правила этой версии:

- каждая активная роль содержит имя игрока;
- каждая роль содержит источник дохода;
- для женских ролей источник дохода пишется явно и практически: лавка, сцена, салон, рента, жалованье, дом, благотворительный фонд, типография, работа руками;
- три около-политические женские роли держат салоны: Манон Ролан, Виктуар де Монфор, Олимпия де Гуж / политический автор;
- предпочтения игроков по осям учитываются как сильный ориентир, но не должны ломать сюжетную функцию роли;
- старые 60 квент не удаляются: это источник материала и резерв.

Файлы:

- `active_tz.md` - ТЗ на 26 активных ролей;
- `active/` - первые рабочие файлы активных ролей;
- `secondary/` - место для 14 коротких второстепенных карточек.
