Промпты уровней

Уровень 1. Понять реестр и формат: считать characters.jsonl источником истины, отличать технические группы group от сословий экономики.

Уровень 2. Проверить артефакты: bios = наличие биографии, links = связи, final/*_kventa.md = текущая сборка, final/*.md без суффикса = старые варианты.

Уровень 3. Сопоставить с экономикой: использовать 3 сословия и 17 подгрупп из Economics/estates.md; спорные случаи помечать примечанием, а не прятать.

Уровень 4. Проверить полноту: обязательные блоки квенты, 8-10 ситуаций, 5 связей, 8 осей, лимиты, даты до 1789.

Уровень 5. Проверить связи: известные цели, та же техническая группа, симметрия, ровно 5 связей, отсутствие 1789+ при строгом чтении инструкции.

Покрытие экономики

Текущие 60 персонажей покрывают политический и городской слой лучше, чем экономический срез населения.

Сильное покрытие:

  • двор и роялистское окружение;
  • адвокаты, журналисты, образованные профессионалы;
  • городской рынок, ремесло и городские низы;
  • приходской curé как важный конфликт внутри духовенства.

Слабое или нулевое покрытие:

  • крестьяне: 0 персонажей при том, что экономика выделяет 3 крестьянские подгруппы;
  • регулярное духовенство: 0 персонажей;
  • военный поставщик / крупный купец: 0 персонажей;
  • колониальный плантатор / импортер: 0 персонажей;
  • чиновники и писари: почти только Ролан;
  • отдельная роль солдата/ветерана экономически не оформлена, хотя есть Журдан, Пишегрю и солдат-инвалид.

Если экономика должна играться всеми 50 участниками, текущий набор стоит либо дополнить крестьянскими и коммерческими ролями, либо явно признать, что 60 квент — это политико-городской набор, а экономика крестьян работает через карточки провинций/мастеров.

Финальные квенты

Текущие output/final/*_kventa.md не являются полноценной финальной версией:

  • их только 35, то есть собраны только группы 1-4;
  • у всех 35 файлов обрезан блок убеждений: остается только первая ось Власть;
  • у louis_xvi_kventa.md, vergniaud_kventa.md, larevelliere_kventa.md по 6 связей из-за исходных link-файлов;
  • для 15 горожан нет связей и нет финальной сборки;
  • для 10 роялистов есть group6_links.md, но нет финальной сборки.

Причина в assemble.py:

  • скрипт загружает только group1_links.md-group4_links.md;
  • комментарий скрипта говорит "all 35 characters", но characters.jsonl уже содержит 60;
  • regex для убеждений использует re.MULTILINE и $, из-за чего захватывает только первую строку блока убеждений.

Валидатор

validate.py сейчас недостаточен для аудита:

  • без PYTHONIOENCODING=utf-8 на Windows падает на символах ✓ / ✗;
  • отсутствие связей и осей не считается ошибкой, если их 0;
  • из-за похожей regex-проблемы валидатор не видит 8 осей в bios;
  • он проверяет лимиты, но не проверяет обязательную полноту финальной квенты.
