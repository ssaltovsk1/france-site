# Причины и рычаги революции

Эта папка собирает не хронологию событий, а причинную карту революции: что является корневой причиной, что выступает триггером, кто двигает ситуацию и во что это превращается.

Для ближайшего теста экономики есть отдельный рабочий документ: `../../Economics/gm_first_test_rules_2026-05-11.md`. Он переводит часть причинных цепочек в площадочные правила: зерно на карте, налоговое кольцо вокруг Парижа, государственные запасы, голод, представители, войска, тюрьма и данж с орбизами.

## Как читать эту структуру

Для каждого узла полезно различать четыре слоя:

1. Корневая причина: долг, неурожай, привилегии, церковный раскол, война.
2. Видимый симптом: дорогой хлеб, спор о голосовании, слухи, рекрутчина, дефицит бюджета.
3. Канал действия: толпа, секции, клубы, декреты, реквизиции, местные общины, армия.
4. Последствие: бунт, радикализация, контрреволюция, Террор, Термидор, военная стабилизация.

## Быстрые причинные цепочки

- `долг государства -> попытка новых налогов -> созыв Генеральных штатов -> кризис представительства`
- `привилегии сословий -> ненависть к неравенству -> политизация третьего сословия`
- `неурожай -> нехватка зерна -> дорогой хлеб -> очереди и слухи -> уличное давление`
- `налоговая стена Парижа -> дорогой ввоз товаров -> ненависть к сборщикам -> погром застав`
- `национализация церковных земель -> присяга духовенства -> раскол приходов -> религиозное сопротивление`
- `Варенн + внешняя угроза -> война -> поражения -> подозрение в измене -> Террор`
- `война + рекрутчина + реквизиции + церковный раскол -> Вандея и провинциальные восстания`
- `Террор -> страх и доносы -> усталость элит и общества -> Термидор -> запрос на порядок`

## Главный принцип для игры

Почти любое сильное решение должно решать один кризис и усиливать другой.

Примеры:

- максимум цен помогает городу, но злит торговцев и рождает черный рынок;
- национализация церковных земель дает ресурс государству, но ломает приходскую лояльность;
- мобилизация усиливает фронт, но толкает провинции к сопротивлению;
- Террор подавляет врагов, но выращивает страх перед самими радикалами.
