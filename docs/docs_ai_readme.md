# Docs_ai

Рабочая папка проектных документов по игре `Revolution_France`.

Здесь лежит не один монолитный диздок, а несколько слоёв: живые правила, база поиска, проектные заметки, генераторы квент и старые версии. Чтобы не заблудиться, ниже зафиксирован статус каждого блока.

## Главное сейчас

Ближайший рабочий фокус — первый тест экономики:

- `DOCS_AUDIT_2026-05-11.md` — текущий аудит документации: что нужно, что справочное, что архивировать.
- `Economics/gm_first_test_rules_2026-05-11.md` — компактные правила теста: принципы, механики и порядок такта.
- `Economics/gm_temporary_answers_2026-05-11.md` — временные ответы мастеров, из которых собран тестовый пакет.
- `Economics/gm_questions_2026-05-11.md` — вопросы, которые ещё не стали утверждёнными правилами.
- `Economics/README.md` — полный вход в экономический блок.

## Активные блоки

| Папка | Статус | Что внутри |
|---|---|---|
| `Economics/` | активная разработка | экономика, зерно, хлеб, налоги, параметры, симулятор, решения и последствия |
| `RevolutionDatabase/` | активная навигация | короткие карточки, теги, поиск, открытые вопросы, ссылки на исходники |
| `_docs/` | активные проектные заметки | описание игры, встречи, причины революции, модели, материалы и большие заметки |
| `_v4/` | источник генерации квент | последняя большая генерация: 60 персонажей, биографии, связи, финальные квенты |
| `_people/` | сырьё по типажам | заметки по обычным и знатным людям |

## Технические и старые блоки

| Папка | Статус | Что с ней делать |
|---|---|---|
| `revolution_game/` | старый генератор квент | не использовать как основной вход; полезен только для воспроизводимости старого пайплайна |
| `_v3/` | старая версия генерации | держать как исторический слой; не брать для актуальных загрузов |
| `_archive/` | архив дублей и старых технических пакетов | не читать по умолчанию |

Актуальные загрузы для работы вынесены отдельно в `../kventa_repo/`. Если цель — редактировать или выдавать игрокам квенты, лучше начинать там, а не в `_v4/output/final`.

## Как читать

1. Для общего смысла игры: `_docs/Описание игры.md`.
2. Для рамки актов и тактов: `_docs/Механики 3 акта 4 такта.md`.
3. Для причинной карты: `_docs/Причины и рычаги революции/README.md`.
4. Для экономики ближайшего теста: `Economics/gm_first_test_rules_2026-05-11.md`.
5. Для поиска по материалам: `RevolutionDatabase/README.md`.
6. Для персонажей: `../kventa_repo/README.md`.

## Что можно архивировать позже

- `_v3/` можно перенести в `_archive/_v3/`, когда станет ясно, что никто не сравнивает старую генерацию с новой.
- `revolution_game/` можно перенести в `_archive/revolution_game_legacy/`, если старый `orchestrator.sh` больше не нужен.
- Сырые транскрипты встреч из корня проекта лучше собрать в отдельный `Archive/meetings/` или перенести в `_docs/Встречи/`, но только после проверки, что из них уже сделаны нормальные заметки.

## Правило пополнения

Новые рабочие решения пишем не в старые генераторные папки, а в один из активных слоёв:

- экономика и правила теста — в `Economics/`;
- причинные и проектные заметки — в `_docs/`;
- короткие карточки и поисковые индексы — в `RevolutionDatabase/`;
- актуальные загрузы — в `../kventa_repo/`.
