Проверены обязательные источники из `Docs_ai/Economics/`. Для сайта опубликованы копии в `france-site/docs/economy/`; оригиналы не удалялись.

## Дубли и оговорки

| Файл | Роль |
|---|---|
| [groups.md](groups.md) | дублирует часть данных из доходов и расходов, но нужен для игровой шкалы касс |
| [estates.md](estates.md) | дублирует доходы/расходы по сословиям, но нужен как быстрый справочник траекторий |
| [historical_audit_and_model.md](historical_audit_and_model.md) | не первичный источник чисел, а проверочная рамка и модель давления |
| [characters_estates_economy_model.md](characters_estates_economy_model.md) | не макроэкономика, а слой «персонаж -> экономика» |
| [people_rashodi.md](people_rashodi.md) | включён как справочный черновик; данные полезны, но формат нужно привести к таблицам |

## Что добить после этого раздела

| Недостача | Почему важно |
|---|---|
| Карточки провинций | без них нет второй стороны хлебного конфликта: деревня продаёт, город покупает |
| NPC военный поставщик | война богатеет через поставщиков, но среди 60 персонажей прямой роли нет |
| NPC колониальный импортёр | Сан-Доминго и колониальная торговля важны для доходов крупной буржуазии |
| Чистая версия `people_rashodi.md` | расходы третьего сословия должны быть в таблицах, как у духовенства и дворянства |
