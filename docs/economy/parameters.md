# Параметры экономики

10 публичных параметров на табло (в 7 «зонах») + скрытые на листе GM.
Каждый имеет: старт, фоновое давление, реакции на шоки и декреты.

Цель документа: основа для расчётного скрипта (`sim/`). Каноничные формулы и калибровка коэффициентов — здесь; код в `sim/engine.py` следует этим определениям.

## 1. КАЗНА (`treasury`)

Чистый остаток. Минус = долг.

| | |
|---|---|
| Старт | **−4000** (млн ливров; долг к 1788) |
| Шкала | −∞ … +∞ |
| Калибровка | −4000 = состояние Акта I (банкротство близко) · −6000 = коллапс кредита (триггер 1797) · 0 = паритет |
| Фон | **−100/такт** (проценты по долгу) |

**Расход на войну** (ступенчато, каждый такт):
- `war_intensity` ≥ 30 → −150
- `war_intensity` ≥ 60 → −300
- `war_intensity` ≥ 100 → −500

**Шоки:**
- Эмиссия 1 млрд ассигнат: +1000 (или +50 в режиме гиперинфляции)
- Контрибуции (Акт IV, war ≥ 30): +50…+200 в зависимости от интенсивности

**Декреты-конверторы:**
- Конфискация церкви: см. `church_reserves`
- Банкротство 2/3: +4000 (одноразово; сопровождается `metal_supply −200`, `army_loyalty −20`)

## 2. РЕЗЕРВЫ — три раздельных шкалы

Принцип №8: резервы съедаются однократно, не восстанавливаются. Разделение показывает разные жизненные циклы.

### 2.1 `church_reserves` — церковь

| | |
|---|---|
| Старт | **100** |
| Шкала | 0 = всё конфисковано · 100 = всё на месте |
| Фон | 0 (только от декретов) |

Декреты переводят из `church_reserves` в `biens_capital` и казну. Историческая дуга: к концу Акта II уходит к 0.

### 2.2 `emigrant_reserves` — эмигранты

| | |
|---|---|
| Старт | **0** (эмиграция начинается) |
| Шкала | 0 … 80 (~150 тыс. эмигрантов, исторический потолок) |
| Фон | **+1/такт** (волны эмиграции) |

**Шоки:**
- Бегство в Варенн: +5
- Казнь короля: +10
- Закон о подозрительных: +5

Декреты конфискации переводят в `biens_capital`. Уникально: растёт ИЗ событий, потом съедается.

### 2.3 `biens_capital` — биены в обороте

| | |
|---|---|
| Старт | **0** |
| Шкала | 0 … ∞ (стоимость в обороте, млн ливров) |
| Фон | 0 |

Питается от `church_reserves` и `emigrant_reserves` через конфискации. Продажа на аукционе: эффективность зависит от `assignat_rate` (при низком курсе государство получает за биены номинал, обесцененный курсом).

## 3. ХЛЕБ ПАРИЖ (`bread_paris`)

Индекс цены 4-фунтовой буханки.

| | |
|---|---|
| Старт | **100** (= 14.5 су, лето 1789, голодный год) |
| Шкала | 50 = норма хорошего года · 100 = голод 1789 · 150 = тревога · 200 = бунт-критика · 500+ = хаос |
| Фон | **+4/такт** (сезонность, военные закупки, дороги; +5 если война ≥ 30) |
| Минимум | 30 (даже в лучший год) |

**Шоки:**
- Неурожай: +30
- Реквизиция в провинциях: −10 в Париж (компенсация)

**Декреты:**
- Максимум цен: `bread_paris` → 100 (фикс), но `black_market` +30, плюс «обманный сигнал» через 3 такта если разрыв велик
- Реквизиция: эффект «реквизиция активна» (см. эффекты): `bread_paris` −3/такт, `rural_unrest` +5/такт

## 4. КУРС АССИГНАТА (`assignat_rate`)

Стоимость бумаги относительно монеты.

| | |
|---|---|
| Старт | **100** (паритет; до первой эмиссии параметр спит) |
| Шкала | 100 = паритет · 50 = бумага вдвое · 5 = коллапс |
| Фон | по формуле (см. ниже) |

**Формула пересчёта** (используется скриптом, не показывается на табло):

```
assignat_rate = max(5, 100 × metal_supply / (metal_supply + 0.2 × assignat_supply))
```

После каждого такта (если `assignat_active = True`) параметр пересчитывается из денежной массы. Шоки на курс конвертируются в шоки на `metal_supply` или `assignat_supply` через декреты/события.

**Триггеры производные:**
- `assignat_rate` ≤ 10 → включается эффект `hyperinflation` (новые эмиссии дают 5% от номинала)
- `assignat_rate` ≤ 5 → эффект `assignat_collapsed`, `assignat_supply` → 0, ассигнат отключён

## 5. ВОЙНА (`war_intensity`)

Интенсивность внешнего конфликта.

| | |
|---|---|
| Старт | **0** (мир, 1788) |
| Шкала | 0 = мир · 30 = ограниченная (1 фронт) · 60 = большая · 100 = тотальная (1793–94) · 200 = пик мобилизации |
| Фон | 0 |

**Шоки:**
- Объявление войны Австрии (Акт II — апрель 1792): +30
- Военное поражение: +10
- Военная победа: 0 (бойня продолжается, противник не сдаётся)
- Казнь короля: +10 (коалиция расширяется)
- Бунт в Париже: +5 (часть пара ушла во внутреннюю смуту)
- Вандейский мятеж: +20 (внутренний фронт)

**Декреты:**
- Объявление войны: +30
- Levée en masse (1793): +20, `army_funding` +30, `rural_unrest` +10

## 6. НАРОД — две шкалы (раскол)

Принцип №5: раскол внутри третьего сословия — главный конфликт. Хлебные декреты бьют две шкалы в противоположные стороны.

### 6.1 `city_unrest` — народ-город

Подёнщики, ремесленники, мелкие лавочники. **Покупатели** хлеба.

| | |
|---|---|
| Старт | **70** |
| Шкала | 30 = спокойно · 60 = тревога · 80 = марши · 95 = бунт-критика · 100 = восстание · 110 = жёсткий потолок |
| Фон | **+1/такт** (если нет cooldown'а после бунта) + давление от хлеба + давление от ассигната |

**Давление от хлеба** (нелинейное, с насыщением):
```
+ sqrt(max(0, bread_paris − 100)) × 1.5
```
- bread_paris=120: +6.7
- bread_paris=200: +15
- bread_paris=300: +24

**Давление от ассигната:** +5/такт если `assignat_rate` < 50.

**Декреты:**
- Максимум цен: `city_unrest` −20 разово
- Если фактическая цена выше Максимума 3 такта подряд (`black_market` > 50) → `city_unrest` +10
- Террор: `city_unrest` −15 разово, +5/такт откат пока активен
- Раздача биенов мелкими лотами: `city_unrest` −10

**Триггер бунта-город:** `city_unrest` ≥ 95 + (упоминание эмиссии/максимума/террора/репрессий/Ле Шапелье в событиях такта ИЛИ `bread_paris` > 200)

При срабатывании:
- `war_intensity` += 5 (внутренняя смута)
- `city_unrest` += −30 (выпустили пар)
- cooldown 2 такта (фон не накапливается)
- При 3-м и далее бунте: `army_loyalty` −5, `treasury` −50

### 6.2 `rural_unrest` — народ-деревня

Крестьяне-собственники + издольщики. **Продавцы** зерна.

| | |
|---|---|
| Старт | **60** |
| Шкала | та же · 110 = жёсткий потолок |
| Фон | **+1/такт** (если нет cooldown'а после Вандеи) |

**Шоки:**
- Реквизиции активны: `rural_unrest` +5/такт (в активных эффектах)
- Levée en masse: +10 (рекруты из деревни)
- Безусловная отмена сеньориальных прав: −20 разово (деревня привязывается к революции)

**Декреты:**
- Максимум на хлеб: `rural_unrest` +5/такт пока активен (бьёт по продавцам)
- Реквизиция: +20 разово + +5/такт пока активна
- Гражданская конституция духовенства: +10 разово
- Антиклерикальный декрет: +10

**Триггер бунта-деревня (Вандея):** `rural_unrest` ≥ 95 + (упоминание гражданской конституции / реквизиции / levée / набора в такте, ИЛИ эффект «реквизиция» активен)

При срабатывании:
- `war_intensity` += 20
- `provinces_loyalty` −20
- `rural_unrest` += −20
- cooldown 2 такта
- Включается эффект `vendee` (см. ниже)

**Раскол в действии:** Максимум на хлеб даёт `city_unrest` −20 и `rural_unrest` +5/такт. Реквизиция даёт `bread_paris` −10 (хорошо для города) и `rural_unrest` +20 (плохо для деревни).

## 7. ПРОВИНЦИИ (`provinces_loyalty`)

Лояльность Парижу как центру.

| | |
|---|---|
| Старт | **80** |
| Шкала | 0 = массовое отделение (Вандея + федералистский кризис 1793) · 100 = полная лояльность |
| Фон | **−2/такт** (центробежная тенденция) |

**Шоки:**
- Парижские эксцессы (массовые казни): −5
- Антиклерикальный декрет: −5…−10 (католические провинции)
- Бегство в Варенн: −10
- Казнь короля: −15

**Декреты:**
- Назначение комиссаров (représentants en mission): +10 разово, −5/такт пока активен (через эффект `commissars`)
- Военное подавление мятежной провинции: +20

**Триггер `federalism`:** `provinces_loyalty` ≤ 30 → включается эффект:
- `treasury` −100/такт пока активен
- `army_loyalty` −2/такт

**Снятие `federalism`:** `provinces_loyalty` > 50.

## Скрытые параметры (на листе GM)

### `black_market` — чёрный рынок

| | |
|---|---|
| Старт | 0 |
| Растёт | +30 при включении Максимума, +5/такт пока активен · +30 при запрете монеты |
| Падает | −20 при отмене Максимума |

**Эффект:** `black_market` > 50 при активном Максимуме → реальная цена хлеба = `bread_paris` × (1 + `black_market`/100). Ощущение, что Максимум держит цену, но в зале хлеба нет.

### `army_funding` — финансирование армии

| | |
|---|---|
| Старт | 100 |
| Падает | −10/такт при `treasury` ≤ 0 (без банкротства) · −5/такт при `war_intensity` ≥ 60 без поставок |
| Растёт | +30 при levée en masse · +10…+20 при контрибуциях в Акте IV |

### `army_loyalty` — лояльность армии

| | |
|---|---|
| Старт | 80 |
| Падает | −20 при банкротстве · −5/такт при контрибуциях с 1796 (генералы держат деньги) · −2/такт при федерализме · −5 за каждый бунт после 3-го |
| Растёт | +5 при подавлении вандемьерского восстания |

**Триггер переворота:** `army_loyalty` ≤ 20 + `war_intensity` ≥ 60 + Акт ≥ 4 → переворот (Бонапарт берёт власть).

### `metal_supply`, `assignat_supply` — денежная масса

| | |
|---|---|
| `metal_supply` старт | 1000. Падает: −10/такт после первой эмиссии (тезаврация), −30 при военном поражении (страх), −200 при банкротстве |
| `assignat_supply` старт | 0. +1000 на каждый млрд эмиссии |

Используются формулой пересчёта `assignat_rate` (см. §4).

## Различия по актам

Правила переписываются между актами (`principles.md`: «структура расходов переписывается между актами»). Скрипт распознаёт акт по такту:

| Акт | Тактовый диапазон | Календарь |
|---|---|---|
| I | T0–T5 | 1789 H1 — 1791 H2 |
| II | T6–T9 | 1792 H1 — 1793 H2 |
| III | T10–T11 | 1794 H1 — 1794 H2 |
| IV | T12+ | 1795 H1 — 1799 H2 |

**Акт I:** `war_intensity` = 0, ассигнат спит до первой эмиссии (декабрь 1789).
**Акт II:** война включается шоково, эмиссия — главный канал казны, Максимум как ключевой декрет.
**Акт III:** Максимум отменён → `bread_paris` взрывается; биены продаются за обесценивающуюся бумагу.
**Акт IV:** контрибуции включаются как доход (`war_intensity` ≥ 30 → +50…+200/такт + пополнение `army_funding`); банкротство 2/3 как событие 1797; переворот возможен.

## Связь с 8 идеологическими осями

Декреты пишутся как пары: эффект на параметры + сдвиг по идеологическим осям (отдельный документ, ещё не создан).

| Ось | Связанные параметры |
|---|---|
| Власть | `treasury`, `provinces_loyalty`, `army_loyalty` |
| Насилие | `city_unrest`, `rural_unrest`, `provinces_loyalty`, `army_loyalty` |
| Война | `war_intensity`, `treasury`, `army_funding` |
| Хлеб | `bread_paris`, `city_unrest`, `rural_unrest` (всегда противоположно) |
| Церковь | `church_reserves`, `rural_unrest`, `provinces_loyalty` |
| Центр / провинция | `provinces_loyalty`, `treasury`, `rural_unrest` |
| Собственность | `church_reserves`, `emigrant_reserves`, `biens_capital`, `assignat_rate` |
| Закон / необходимость | `city_unrest`, `army_loyalty` |

## Открытые вопросы

- Финальная калибровка коэффициентов (нелинейная sqrt-формула давления хлеба, ASSIGNAT_FORMULA_COEFFICIENT=0.2 и т.д.) — после 3–5 прогонов в разных сценариях
- Карты декретов как файл с числовыми эффектами (`decrees.md`)
- Идеологические оси с числовыми сдвигами (отдельный документ)
- Шоки: в симуляторе могут быть расписаны для калибровки, но в живой игре должны срабатывать по условиям, решениям игроков и внешнему контуру
- Кассы 7 групп — детальная индивидуализация финансов сословий (сейчас агрегат)
