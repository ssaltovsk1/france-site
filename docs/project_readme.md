# Revolution France

Рабочая папка ролевой игры про Французскую революцию.

## Быстрый вход

- `Docs_ai/README.md` — карта рабочих проектных документов и статусов папок.
- `Docs_ai/DOCS_AUDIT_2026-05-11.md` — аудит документации: что нужно, что справочное, что можно архивировать.
- `Docs_ai/RevolutionDatabase/README.md` — короткая навигационная база: теги, карточки, поиск по материалам.
- `Docs_ai/_docs/Описание игры.md` — общий смысл и описание игры.
- `Docs_ai/_docs/Механики 3 акта 4 такта.md` — общая рамка актов и тактов.
- `Docs_ai/_docs/Причины и рычаги революции/README.md` — причинная карта революции.
- `Docs_ai/Economics/README.md` — вход в экономический блок.
- `Docs_ai/Economics/gm_first_test_rules_2026-05-11.md` — рабочие правила первого теста экономики: принципы, механики и порядок такта.
- `kventa_repo/README.md` — актуальные загрузы персонажей, вынесенные в отдельный git-репозиторий.
- `Docs/README.md` — карта справочных и дизайн-референсных материалов.
- `Docs/MechanicsAtlas/README.md` — компактный слой механик поверх сырого архива.
- `log.md` — общий журнал проектных решений.

## Текущий фокус

На 2026-05-11 главный рабочий пакет для ближайшего прогона — `Docs_ai/Economics/gm_first_test_rules_2026-05-11.md`.

Он фиксирует:

- что должно быть видно на карте;
- как движутся зерно, хлеб, представители и войска;
- как работает налоговое кольцо вокруг Парижа;
- как государство покупает, запасает и выдает зерно;
- как работает голод;
- что происходит в ходе / такте;
- как обрабатываются аресты, тюрьма и силовые конфликты через данж с орбизами.

Статус документа: рабочие правила первого теста, не финальная версия игры.

## Статусы крупных блоков

| Блок | Статус | Как использовать |
|---|---|---|
| `Docs_ai/Economics/` | активный рабочий блок | экономика, карта, зерно, хлеб, налоги, войска, тюрьма, правила ближайшего теста |
| `Docs_ai/RevolutionDatabase/` | активный навигационный слой | быстрый поиск по историческим узлам, механикам, загрузам и открытым вопросам |
| `Docs_ai/_docs/` | активные проектные заметки и источники | описание игры, причины революции, встречи, материалы, большие заметки |
| `kventa_repo/` | активные загрузы | чистая рабочая папка для 60 актуальных квент персонажей |
| `Docs/MechanicsAtlas/` | активный дизайн-слой | выбирать и адаптировать механики из сырья под `Revolution_France` |
| `Docs/Ballance/`, `Docs/GameDesign/` | справочная библиотека | источники и выжимки по гейм-дизайну и балансу, не текущие правила игры |
| `Docs_ai/_v4/` | источник генерации квент | хранить как генератор/сырьё; для выдачи игрокам лучше брать `kventa_repo/` |
| `Docs_ai/_v3/`, `Docs_ai/revolution_game/`, `Docs_ai/_archive/` | старые или технические слои | не использовать как вход по умолчанию; держать для воспроизводимости и истории |

## Правило навигации

Если нужен ответ "что делать на ближайшей игре" — начинать с `Docs_ai/Economics/gm_first_test_rules_2026-05-11.md`.

Если нужен ответ "где это в материалах и чем подтверждается" — идти через `Docs_ai/RevolutionDatabase/README.md`.

Если нужен ответ "какой загруз отдавать игроку" — идти в `kventa_repo/`.

Если нужен ответ "какую механику взять или доработать" — идти в `Docs/MechanicsAtlas/`.
