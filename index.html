Как выложить на GitHub

  1. Открой репозиторий ssaltovsk1/france-site.
  2. Загрузи содержимое папки france-site, не саму папку.
  3. Включи Pages: Settings -> Pages -> Deploy from a branch -> main / /root.
  4. Через минуту сайт будет доступен как https://ssaltovsk1.github.io/france-site/.
