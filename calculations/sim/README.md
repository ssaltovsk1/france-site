# Симулятор экономики

Расчётная модель параметров из `../parameters.md`.
Такт = полугодие. Прогон детерминированный.

Важно: «сценарий» в этой папке — технический калибровочный прогон для проверки формул. Это не сценарий живой игры и не обязательная последовательность событий для мастеров.

## Запуск

```bash
cd sim
python run.py            # Акт I (7 тактов)
python run.py full       # Акты I-IV (21 такт)
python run.py act1 --no-plot
```

Зависимости: `matplotlib`. Без него — лог + CSV.

```bash
pip install matplotlib
```

## Файлы

| Файл | Назначение |
|---|---|
| `state.py` | Dataclass `State` — все параметры (читаемые имена), эффекты, история. `DISPLAY_NAMES` — соответствие имён в коде → русские лейблы для табло |
| `engine.py` | Цикл такта: фон → действия → эффекты → расход войны → формула ассигната → триггеры → клампы → cooldown'ы |
| `library.py` | Декреты и шоки как функции `(state) -> None` |
| `scenarios.py` | Расписания действий по тактам |
| `run.py` | Точка входа: лог в stdout, CSV, графики |

## Параметры

10 публичных + 5 скрытых. Полный справочник — в `../parameters.md`.

**Публичные:**
- `treasury` (казна), млн ливров
- `church_reserves`, `emigrant_reserves`, `biens_capital` (резервы — три шкалы)
- `bread_paris` (хлеб Париж, индекс)
- `assignat_rate` (курс ассигната, индекс)
- `war_intensity` (война)
- `city_unrest`, `rural_unrest` (народ — два, раскол)
- `provinces_loyalty` (провинции)

**Скрытые:**
- `black_market` (чёрный рынок)
- `army_funding`, `army_loyalty` (армия)
- `metal_supply`, `assignat_supply` (денежная масса)

## Цикл такта

1. **Фон.** Проценты по долгу, дрейф цены хлеба, sqrt-давление от P на город, тезаврация монеты, центробежная тенденция Pr, эмиграция.
2. **Действия такта.** Декреты и шоки из калибровочного сценария.
3. **Активные эффекты.** Максимум, реквизиции, Террор, Вандея, Федерализм, Гиперинфляция — каждый со своей per-tick дельтой; Вандея саморазрешается при условиях.
4. **Расход войны.** При war ≥ 30: −150; ≥ 60: −300; ≥ 100: −500.
5. **Пересчёт ассигната.** `assignat_rate = max(5, 100 × metal_supply / (metal_supply + 0.2 × assignat_supply))`.
6. **Триггеры.** Бунт-город, бунт-деревня, банкротство, федерализм, гиперинфляция, коллапс ассигната, переворот.
7. **Кламп шкал.** city/rural ≤ 110, prov ≤ 100, army_funding ≥ 0, и т.д.
8. **Cooldown'ы.** −1 счётчику городского/деревенского cooldown'а.

## Калибровка

Коэффициенты в `engine.py` (вверху файла) — стартовые ориентиры под полугодовой такт.

| Константа | Значение | Что регулирует |
|---|---|---|
| `TREASURY_INTEREST_PER_TICK` | −100 | Проценты по долгу |
| `BREAD_DRIFT_PER_TICK` | +4 | Базовый рост цены хлеба |
| `CITY_PRESSURE_FROM_BREAD_K` | 1.5 | Давление хлеба на город (множитель к sqrt) |
| `ASSIGNAT_FORMULA_COEFFICIENT` | 0.2 | Скорость падения курса ассигната |
| `WAR_COST_LOW/HIGH/TOTAL` | −150/−300/−500 | Расход казны на войну |
| `RIOT_COOLDOWN_DURATION` | 2 такта | Защёлка против цикличных бунтов |
| `VENDEE_MIN_DURATION` | 3 такта | Минимум до подавления Вандеи |

## Добавить декрет

В `library.py`:

```python
def my_decree(s: State) -> None:
    s.treasury -= 100
    s.city_unrest += 5
    s.events.append("Декрет: мой новый декрет")
```

В словарь `DECREES`:

```python
DECREES = {
    ...,
    "my_decree": my_decree,
}
```

В сценарий:

```python
SCENARIO_X = [
    ...,
    (5, "my_decree"),
]
```

## Добавить шок

То же самое, но в `SHOCKS`.

## Свой сценарий

В `scenarios.py`:

```python
SCENARIO_TEST = [
    (1, "abolish_privileges"),
    (2, "first_assignat_emission"),
    ...
]
TEST_TICKS = 5
```

В `run.py` добавить ветку или вызвать из своего скрипта:

```python
from run import run
from scenarios import SCENARIO_TEST, TEST_TICKS
```

## Активные эффекты

Эффект — модификатор с длительностью. Включается/снимается через `state.add_effect(name)` / `remove_effect(name)`. Каждый такт обрабатывается в `apply_active_effects()`.

| Имя | Включается | Снимается | Эффект |
|---|---|---|---|
| `maximum` | декретом Максимум | декретом отмены | `black_market` +5/такт; `rural_unrest` +5/такт; через 3 такта при B>50 — «обман» (+10 city_unrest) |
| `requisition` | декретом реквизиции | декретом остановки | `rural_unrest` +5/такт; `bread_paris` −3/такт |
| `terror` | декретом Террора | концом Террора / термидором | через 1 такт активности — +5 city/+3 rural откат |
| `commissars` | декретом комиссаров | (вручную) | `provinces_loyalty` −5/такт |
| `vendee` | бунтом-деревней | автоматически (3+ такта, армия_финанс ≥ 20, нет реквизиции) | `treasury` −50/такт; `army_funding` −3/такт |
| `federalism` | при `provinces_loyalty` ≤ 30 | при `provinces_loyalty` > 50 | `treasury` −100/такт; `army_loyalty` −2/такт |
| `hyperinflation` | при `assignat_rate` ≤ 10 | (необратимо) | `city_unrest` +2/такт; новые эмиссии = 5% от номинала |
| `assignat_collapsed` | при `assignat_rate` ≤ 5 | (необратимо) | ассигнат отключён, `metal_supply` +5/такт восстановления |

## Лог

Каждый такт выводит:
- Заголовок `T<tick> | <дата> | Акт <N>`
- Две строки публичных параметров (имя=значение)
- Строка скрытых параметров
- Cooldown'ы (если активны)
- Активные эффекты
- События такта (декреты, шоки, триггеры)

## Графики

`run.py` строит сетку 3×2:
1. Казна (с порогом банкротства)
2. Резервы (3 кривые)
3. Хлеб + Ассигнат + Чёрный рынок
4. Война + Армия (финанс + лояльность)
5. Напряжённость (город + деревня) + Провинции (с порогами бунта и федерализма)
6. Денежная масса (монета + ассигнаты, log-шкала)

## CSV

Все параметры по тактам, разделитель `;`, кодировка UTF-8 BOM (для Excel). Заголовки колонок — русские лейблы.

## Ограничения текущей версии

- Параметры на уровне агрегата. Кассы 7 групп не считаются индивидуально.
- Нет случайности. В калибровочных сценариях шоки заданы расписанием; в живой игре они должны зависеть от решений игроков и внешнего контура.
- Нет идеологических осей (отдельный документ).
- Нет UI — редактирование сценариев через код.
