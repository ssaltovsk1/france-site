# Resource Projection Lab

Папка для прикладного моделирования ресурсов живой игры.

Открывать: `index.html`.

Модель считает не всю экономику, а те места, где быстро возникает игровой кризис:

- хлеб и зерно по состояниям: рынок, церковь, черный рынок, дорога, булочник, тайник, реквизиция;
- игроков группами: бедные, рабочие, ремесленники, служащие, собственники;
- покупку хлеба, помощь церкви, черный рынок, долги, голод;
- казну, невыплаты, ассигнаты, доверие к бумаге;
- цену хлеба, городское/деревенское напряжение и черный рынок.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | Статическая панель с контролами, графиками и таблицей |
| `data/scenarios.js` | Стартовые сценарии и параметры групп |
| `src/model.js` | Движок расчета по ходам |
| `src/charts.js` | Canvas-графики без внешних зависимостей |
| `src/app.js` | Связь UI, сценариев и модели |
| `smoke_test.js` | Быстрая проверка всех сценариев через Node.js |

## Сценарии

- `Базовая поставка`
- `Поставки застряли`
- `Максимум без подвоза`
- `Жалованье ассигнатами`
- `Скупка богатыми`
- `Война и реквизиции`

## Как читать

- `Массовый голод` — первый ход, где 5+ игроков остались без хлеба.
- `Рынок пустеет` — первый ход, где легального хлеба на рынке не осталось.
- `Казна пустеет` — первый ход, где государственная монета дошла до нуля.
- `Богаче всех / беднее всех` — финальная разница групп по деньгам минус долги на игрока.

Это калибровочный инструмент. Числа не финальные: их лучше менять после каждого плейтеста и сравнивать, в какой момент появляется нужный уровень дефицита, долга, черного рынка и политического давления.
